OUTKAST 2.0.0 is the complete navigation and identity refresh. It replaces the persistent navigation
bar and legacy side drawer with Orbit: edge gestures move through Feed, Discover, Long reads and Inbox,
while the compact control surface exposes Recent, Recent with replies, Algorithms, Bookmarks, Profile
and Settings. The feed header is reduced to a centered OUTKAST wordmark and the product tagline.

Every active Android data path remains relay-native — no Primal cache server is required for feeds,
profiles, threads, notifications, DMs, search, bookmarks, mute lists, articles or zaps. Existing
accounts, databases, Keystore material, signing identity and `com.librenostr.android` upgrade
compatibility are preserved.

See [CHANGELOG.md](https://github.com/Lwb89dev/outkast/blob/main/CHANGELOG.md) for the full list of changes.
