OUTKAST 2.1.0 makes moving between worlds work on phones with gesture navigation, and adds a way into
a photo's comments.

Swipe sideways from anywhere on the screen to go to the next or previous world — Feed, Discover,
Long reads, Inbox. Horizontal scrollers keep their own swipes and hand the swipe over only on their
last page. The edge swipe stays as a shortcut. Swiping up on a photo or video in the full-screen viewer
opens the note's thread with its replies. Picking the feed that is already showing in Orbit now
refreshes it, and a crash in Discover's Feed gallery caused by a duplicated feed is fixed.

Existing accounts, databases, Keystore material, signing identity and `com.librenostr.android` upgrade
compatibility are preserved.

See [CHANGELOG.md](https://github.com/Lwb89dev/outkast/blob/main/CHANGELOG.md) for the full list of changes.
